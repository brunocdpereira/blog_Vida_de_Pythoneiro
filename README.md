#  Vida de Pythoneiro

Meu primeiro projeto desenvolvido com **Python e Django**.

Este projeto nasceu como uma forma de aprender desenvolvimento web utilizando Python, Django, HTML e CSS, colocando em prática os conceitos aprendidos durante o desenvolvimento.

##  Sobre o projeto

O **Vida de Pythoneiro** é um blog desenvolvido com Django onde é possível publicar e gerenciar artigos, desenvolvido por Bruno Pereira.

O projeto está sendo desenvolvido passo a passo, começando com funcionalidades simples e evoluindo conforme novos conhecimentos são adquiridos.

##  Funcionalidades

Atualmente o blog possui:

* Listagem de artigos
* Criação de novos artigos
* Exibição do autor
* Exibição do e-mail do autor
* Sistema de Like
* Sistema de Dislike
* Edição de artigos
* Exclusão de artigos
* Formatação do conteúdo dos artigos
* Layout personalizado com CSS
* Link para contato via WhatsApp

##  Tecnologias utilizadas

* Python
* Django
* HTML5
* CSS3
* SQLite

##  Como executar o projeto

### 1. Clone o projeto

```bash
git clone URL_DO_REPOSITORIO /blog_Vida_de_Pythoneiro
```

Entre na pasta:

```bash
cd vida-de-python
```

### 2. Crie o ambiente virtual

Windows:

```bash
python -m venv venv
```

### 3. Ative o ambiente virtual

No Windows:

```bash
venv\Scripts\activate
```

### 4. Instale as dependências

```bash
pip install dependencias
```

### 5. Execute as migrações

```bash
python manage.py migrate
```

### 6. Inicie o servidor

```bash
python manage.py runserver
```

Abra no navegador:

```text
http://127.0.0.1:8000/
```
